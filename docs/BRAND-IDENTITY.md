# DevOps by hmrdkn-labs — brand identity

2026-09-21 · P2 cropped beaver mark

## Logo system

The DevOps by hmrdkn-labs identity uses the selected A1 beaver character with
the **P2 lower-right peeking pose** as the product mark. The production mark is
a tight crop of P2: the face is dominant, both ears remain visible, and the
paddle tail still provides the beaver cue. The crop removes most of the lower
body so it reads like an IP logo at 32px instead of a full character illustration.

The full A1 character remains available on larger welcome/help surfaces. These
are two presentations of the same identity with different jobs: compact mark
for navigation/app chrome, full character for friendly learning moments.

## Core colors

- body: `#E7A267` honey-apricot
- tail and facial marks: `#563A2F` deep walnut
- mark background: `#A9C2E8` muted cornflower blue
- light wordmark: `#202B33`; secondary `#52616B`
- dark wordmark: `#F1F3F5`; secondary `#B2BEC9`

Do not recolor the mark to represent success, failure, mastery, or theme state.
Interface semantic colors carry those meanings.
